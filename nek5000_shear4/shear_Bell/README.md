# shear_21 — doubly periodic double shear layer (Nek5000)

Thick-layer double shear-layer roll-up, the standard test of a projection
method's behaviour when the layers thin below grid resolution.

**Reference:** J. B. Bell, P. Colella, and H. M. Glaz, "A second-order
projection method for the incompressible Navier–Stokes equations,"
*Journal of Computational Physics*, vol. 85, no. 2, pp. 257–283, Dec. 1989.
doi:[10.1016/0021-9991(89)90151-4](https://doi.org/10.1016/0021-9991(89)90151-4)

## Problem

Unit square `[0,1]²`, **fully periodic** in both directions, 2-D incompressible.

Initial condition (`useric` in `shear.usr`), with ρ = 30 (thick layer) and
δ = 0.05:

```
u = tanh(ρ(y − 1/4))     y ≤ 1/2          v = δ·sin(2πx)
    tanh(ρ(3/4 − y))     y > 1/2
```

Two counter-rotating shear layers are perturbed transversely; they roll up into
a pair of vortices whose braids thin monotonically with time. The `rho = 100`
thin-layer variant is present but commented out in `useric`.

Re = 10⁵ (`viscosity = -1e5`, i.e. ν = 10⁻⁵ at unit density and unit length).

## Discretization

| | |
|---|---|
| Mesh | 16 × 16 spectral elements, uniform, generated by `genbox` from `shear.box` |
| Order | `lx1 = 9`, `lx2 = 7` → **128 × 128** grid points |
| Over-integration | `lxd = 13` (`dealiasing = yes`) |
| Stabilization | explicit filter, 2 modes, weight 0.05 |
| Time | `dt = 1e-3`, variable dt at `targetCFL = 1`, `endTime = 1.8` |
| Output | `writeControl = runTime`, every 0.1 → 18 field files |

Both stabilizations are on here. Fischer & Mullen (CRAS 2001) showed the filter
alone suffices for this problem; over-integration of the convective term alone
also suffices. This case runs with both, which is conservative.

## Result

Completed to t = 1.8 in **2016 steps** on 4 MPI ranks (Nek5000 20.0-dev,
6.6 s wall). Peak vorticity, monitored each step by `userchk`, stays at
≈ 30.3 — flat from the initial value, i.e. no spurious amplification and no
blow-up. `userchk` also aborts if `max|u| > 8`; that guard never fired.

## Running

```bash
export NEK_SOURCE_ROOT=/path/to/Nek5000
rm -rf *.f0*
genbox && mv box.re2 shear.re2      # feed it shear.box
genmap                              # feed it shear
makenek shear
nekbmpi shear 4
visnek shear
```

`SESSION.NAME` hard-codes `/home/hailu/Nek5000/run/shear4/shear_21/`;
`nekbmpi` rewrites it, or edit it before running elsewhere.
